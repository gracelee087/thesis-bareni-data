# Excluded AsPredicted #309062 dataset

This directory preserves the complete SD-166–SD-290 execution under AsPredicted #309062:
125 task records, frozen batch banks, lesson states, batch journals/status receipts,
telemetry and the resulting analysis. Its `raw_responses/` subdirectory is the active raw
response directory as it existed at closure and also contains a small number of earlier
diagnostic/selection responses; none is eligible for the new study.

The run produced 124 complete records and one pipeline failure (SD-277). Because SD-277
lacked a complete blinded initial/final pair, the preregistered H3 rule yielded
`UNQUALIFIED_MISSING_PAIRS`. The data and analysis were viewed before the subsequent
lesson-revised final study was designed.

Nothing in this directory may enter the H1–H3 analysis, cost ledger, topic allocation or
lesson state of the new SD-291–SD-415 dataset. It is retained only as an immutable audit
trail. The matching preregistration receipt is preserved at
`config/preregistration_history/PREREGISTRATION_RECEIPT_309062.json`.
